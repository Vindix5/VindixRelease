FNF Vs Vindix — сайт (стиль "жидкое стекло")
==============================================

ЧТО ВНУТРИ
  index.html              сам сайт (весь код в одном файле)
  assets/background.mp4   фоновое видео (сжато до ~5 МБ)
  assets/poster.jpg       кадр, пока грузится видео
  assets/logo.png         логотип мода
  assets/icon.png         иконка мода (и иконка вкладки браузера)
  assets/shots/           8 скриншотов для карусели (shot1.jpg ... shot8.jpg)

ЧТО НА САЙТЕ
  - Вкладки сверху: Home, Demo version (прокручивает вниз к демо), Songs (SoundCloud).
  - Карусель скриншотов над таймером: стрелки, точки, листается сама каждые 5 секунд
    (на ПК пауза, пока мышь над каруселью; на телефоне листается свайпом).
  - Таймер релиза 0.1.2 до 15 декабря; потом кнопка Download (страница мода).
  - Внизу блок Demo version 0.1.1 с кнопкой Download (страница демо).

ПРОВЕРКА НА КОМПЬЮТЕРЕ
  Распакуй архив В ОТДЕЛЬНУЮ ПАПКУ и открой index.html в браузере.
  Чтобы увидеть кнопку Download вместо таймера, добавь ?unlock к адресу
  (на опубликованном сайте: адрес/?unlock).

КАК ПОМЕНЯТЬ ДАТУ ИЛИ ССЫЛКИ
  Открой index.html в текстовом редакторе, найди блок CONFIG (внизу):
    var RELEASE = new Date(2026, 11, 15, 0, 0, 0);
  Порядок: год, месяц (0 = январь, 11 = декабрь), день, часы, минуты, секунды.
  Время считается по часам посетителя.
  Ссылка кнопки релиза — DOWNLOAD_URL. Ссылки на демо (gamebanana.com/wips/90241)
  и Songs (SoundCloud) лежат прямо в HTML: найди их поиском (Ctrl+F).

КАК ПОМЕНЯТЬ СКРИНШОТЫ
  Замени файлы в assets/shots (лучше 16:9, ширина около 1280 px).
  Названия shot1.jpg ... shot8.jpg не меняй, либо поправь пути в index.html.

КАК ОПУБЛИКОВАТЬ БЕСПЛАТНО

  Вариант 1 — Netlify Drop (самый простой)
    1. Распакуй zip в папку (index.html должен лежать прямо в ней).
    2. Открой https://app.netlify.com/drop
    3. Перетащи ПАПКУ на страницу. Через несколько секунд получишь
       ссылку вида что-то.netlify.app
    4. Чтобы сайт не пропал, нажми "Claim" и зарегистрируйся.
    Обновить сайт: перетащи новую папку в раздел Deploys этого сайта.

  Вариант 2 — GitHub Pages
    1. Создай репозиторий на github.com (Public).
    2. Загрузи index.html и папку assets (в github.dev: перетащи в Explorer,
       потом Source Control -> Commit -> Push).
    3. Settings -> Pages -> Source: "Deploy from a branch",
       ветка main, папка / (root) -> Save.
    4. Через 1-2 минуты сайт будет по адресу
       https://ТВОЙ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/

  Вариант 3 — Vercel Drop
    https://vercel.com/drop — можно перетащить сам zip-файл.
    Может попросить войти в аккаунт.
